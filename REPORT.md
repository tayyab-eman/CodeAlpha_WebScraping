# CodeAlpha Data Analytics Internship — Project Report

## Task 1 — Web Scraping

### Objective
Collect structured population information from a public web page and store it as a CSV dataset.

### Source
Wikipedia:
https://en.wikipedia.org/wiki/List_of_countries_and_dependencies_by_population

### Method
1. Send an HTTP request using Requests.
2. Parse the returned HTML with BeautifulSoup.
3. Locate the table containing `Location` and `Population`.
4. Extract rows.
5. Clean the population column.
6. Save the result to `data/country_population.csv`.

### Tools
Python, Requests, BeautifulSoup, Pandas.

## Task 4 — Sentiment Analysis

### Objective
Apply NLP sentiment analysis to review sentences.

### Source
UCI Machine Learning Repository:
https://archive.ics.uci.edu/dataset/331/sentiment+labelled+sentences

The UCI page states that the dataset contains 3,000 sentences from IMDb, Amazon and Yelp, with positive/negative labels.

### Method
VADER is used as a lexicon-based sentiment analyzer. Its compound score is converted to:
- Positive
- Negative
- Neutral

The original UCI labels are binary, so the neutral class is an additional output generated by the VADER threshold.

### Output
`outputs/task4_sentiment_results.csv`
